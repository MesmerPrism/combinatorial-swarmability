# Deferred Integrations

## Rusty Optics

Version one keeps palette, appearance, and Canvas projection app-owned. The
current `rusty-optics-particles` package assumes an external sibling Rusty
Matter checkout and is not admitted through a consumer-side patch. A later
owner-side self-contained package strategy may justify a bounded `labs`
dependency migration.

## Public literature catalog

The first private-research-to-public JSON export remains a `locked` boundary.
Only synthetic fixtures are present now.

## Quest and OpenXR

A later Quest adapter should reuse `demo-core`, `SemanticAction`, action
receipts, deterministic fixtures, and Matter payloads. It must not reuse DOM,
Canvas2D, browser animation timing, or browser accessibility policy as XR
runtime authority.

## Multi-user authority

Manifold becomes relevant only when accepted external commands, participants,
sessions, peers, leases, revocation, or replay become real requirements. The
local app reducer is not promoted as a generic authority contract.
