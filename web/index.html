What this slice proves

Independent dimensions

A pointer click, a focused member control, and a low-rate button all become the same semantic requests. The current target scope—not the input device—decides which members receive the action.

Reusable Rust boundary

A deterministic Rust core produces Rusty Matter particle payloads. Canvas drawing and DOM accessibility remain browser adapters, so a later headset route can reuse the core without importing browser code.
